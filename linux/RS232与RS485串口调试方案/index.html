# 串口基础知识

串口常用的分为 RS-232 以及 RS-485

  • RS-232 :
  • 该接口通常使用 DB9 针接口 (只有 9 个针脚) or DB25 (25 个针脚)；
  • RS-232 使用单端信号传输方式 (即一根针脚传输一根针脚接收)
  • RS485 :
  • 该接口不需要特定类型的连接器，它可能使用各种类型的连接器，包括 RJ45、螺丝端子 (如下图接口一所示) 。
  • RS-485 使用半双工 (两根导线) 或全双工 (四根导线) 进行通信

# RS-232 接口

  1. 公头 or 母头

    1. 有针脚的为公头

    2. 没有的为母头

  2. 针脚解释

    引脚 简写 功能说明
    1 CD 载波侦测 (Carrier Detect)
    2 RXD 接收数据 (Receive)
    3 TXD 发送数据 (Transmit)
    4 DTR 数据终端准备 (Data Terminal Ready)
    5 GND 地线 (Ground)
    6 DSR 数据准备好 (Data Set Ready)
    7 RTS 请求发送 (Request To Send)
    8 CTS 清除发送 (Clear To Send)
    9 RI 振铃指示 (Ring Indicator)

  3. 一般只用到 2、3、5 三个引脚；

  4. RS232 是全双工；

  5. RS232 限于 15 米以内，理论传输距离是 10 米；

  6. RS232 螺丝端子

# 安装 minicom & 设置 minicom

  1. 将 minicom_packages.zip 包上传到服务器上并解压 minicom_packages.zip 包

  2. 设置 minicom

    ⚠️警告：以下操作需要在 root 用户下执行，否则保存配置不生效

    1. 输入 minicom -s 打开 minicom 设置

    2. 选择 Serial port setup

      • A - Serial Device : /dev/modem

        指定用于通信的串行设备文件路径

      • C - Callin Program :

        用于指定调制解调器来电执行的脚本

      • D - Callout Program :

        用于指定调制解调器拨出电话执行的脚本

      • E - Bps/Par/Bits : 115200 8N1

        定义串行通信的基本参数

        Bps(Bits per second) : 波特率，即每秒传输的数据位数。此处默认为每秒传输 115200 个数据位.

        Data Bits : 数据位数，表示每个字符由 8 个数据位组成.

        Parity : 校验方式， E (Even, 偶校验). O (Odd, 奇校验). N (None, 不校验)

        Stop Bits : 停止位数，表示每个字符后有一个停止位.

      • F - Hardware Flow Control : Yes

        硬件流控制是否启用

        通常通过 RTS/CTS 信号线 (信号线参见下文) 实现，用于防止数据溢出和丢失

      • G - Software Flow Control : No

        软件流控制是否启用

        通常通过 XON/XOFF 字符实现，用于控制数据流的暂停和回复

    3. 通过输入选项前面的字母来更改对应的设置项，使用 esc 返回 (不保存); 使用 enter(回车) 保存并返回

    4. 在按 E 后显示 Comm Parameters 界面

      • Current 行：该行为当前设置的参数
      • Speed 列：用于设置波特率，使用指定选项选择对应的频率
      • Parity 列：用于设置当前校验方式
      • Data 列：用于设置数据位数
      • Stopbits 列：用于设置停止位的数量

    5. 在全部设置完成后选择 Save setup as dfl 保存为默认设置或选择 Save setup as .. 并指定一个名称来保存当前设置

      设置文件默认保存在 /etc/minirc.dfl 文件中

    6. 保存完成后选择 Exit from Minicom 退出

# 问题汇总

  1. 对于调试过程中出现的 无法在此设备上加载驱动程序 警告弹窗参考以下方法解决

    ⚠️该方法所有步骤仅通过 windows11 执行， windows10 用户请参考使用

    该方法执行完成后需要重启电脑才能生效

    1. 使用 win+x 打开如图选项框，点击设置

    2. 进入设置先点击 隐私和安全性 ，然后点击 windows安全中心

    3. 点击设备安全性

    4. 在安全中心点击内核隔离详细信息

    5. 点击关闭内核隔离

  2. 对于不知道对应串口号的，可以使用 dmesg | grep tty 来查看，如下图

  3. 对于串口打不开或打开失败的情况可以使用 lsof /dev/[需要查看的串口号] 来查看，如果什么都没有输出则没有被任何进程使用，反之可以使用显示的 PID + kill -9 [PID] 来杀掉该进程
